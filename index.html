중3 인수분해 공식 가이드

STAGE 1

공통인수로 묶기

각 항에 공통으로 들어있는 인수를 괄호 밖으로 묶어냅니다.

ma + mb = m(a + b)
STAGE 2

완전제곱식

양 끝 항이 제곱이고 가운데 항이 2 × a × b 형태일 때 적용합니다.

a² + 2ab + b² = (a + b)²
a² - 2ab + b² = (a - b)²
STAGE 3

합차 공식

두 항의 제곱의 차 형태일 때 한 번은 더하고 한 번은 뺍니다.

a² - b² = (a + b)(a - b)
STAGE 4

이차식 (x² 계수가 1인 경우)

합이 b이고 곱이 c인 두 정수 m, n을 찾습니다.

x² + (m + n)x + mn = (x + m)(x + n)
STAGE 5

대각선 멜빵법 (ax² + bx + c)

ax²을 p·r로, c를 q·s로 나누어 대각선 곱의 합(ps + qr)이 b가 되도록 만듭니다.

ax² + bx + c = (px + q)(rx + s)

대각선(멜빵법) 연습장 계산기

⚡ 현재 문제의 계수(a, b, c)가 자동으로 대각선 계산기에 세팅되었습니다!
